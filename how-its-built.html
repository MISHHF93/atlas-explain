How it's built

The technical design behind ATLAS Explain, for developers and for the judges of Google's #BuildHybridAI challenge. Everyday use needs none of this.

Hybrid inference with Firebase AI Logic

Every explanation goes through the Firebase AI Logic Web SDK in hybrid mode, with prefer_on_device as the default.

  1. On the device. When Chrome's Prompt API reports Gemini Nano as available, the prompt runs locally. Nothing leaves the computer, and the answer is labelled "On this device".
  2. In the cloud. When Nano is unavailable (phones, other browsers, older hardware) or the text is too long for it, the same prompt goes to Gemini Flash-Lite in the cloud and is labelled "Cloud".
  3. Private context stays local. Private notes and watchlists are only ever included in on-device prompts. A cloud fallback drops them and says so.

The path that actually ran is read from the SDK's response and shown on every answer. It is never guessed.

Protection and configuration

  • App Check with reCAPTCHA Enterprise is enforced on Firebase AI Logic, so only this site can spend cloud calls.
  • The Chrome extension makes its cloud calls through a hidden page on this site that answers only the published extension id. That way App Check runs on the web origin, and the extension holds no keys.
  • Fair-use limits: each browser is limited to 8 cloud answers a minute and 300 a day. Answers on the device are never limited.
  • Remote Config holds the inference mode, the cloud model, the prompt template, the on-device size limits, the price provider and the billing switch. Built-in defaults apply when it can't be read.
  • Education-only guardrails: a fixed system prompt, refusal of requests for trade decisions, removal of account-like numbers before anything is sent, and a scan in the release check that blocks trade-instruction wording.

Data

  • Live crypto prices come from a public market-data provider (Kraken or CoinGecko, chosen in Remote Config). The provider is named and linked next to every price, with its time.
  • No fixtures. Missing data is shown as missing, with the reason.
  • ATLAS research desk. ATLAS Explain can also read the public signal of the ATLAS research software when that software runs on the same computer. That integration is optional and is hidden for everyone who doesn't run ATLAS. Its paper predictions stay withheld until they pass a published evidence gate.

Stack

  • TypeScript with Vite, no UI framework. The app's routes are lazy-loaded.
  • Chrome extension (Manifest V3): a popup and a side panel built from the same components as the web app, a context-menu entry and keyboard shortcuts.
  • Firebase: AI Logic, App Check, Remote Config, Authentication (Google and email link), Firestore with owner-only rules, and Hosting.

Source and local install

The code is open source under Apache-2.0 at github.com/MISHHF93/atlas-explain. To build the extension yourself, run npm ci, then npm run build:extension, and load extension/dist as an unpacked extension in chrome://extensions.
