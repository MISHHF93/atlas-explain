Built to be trusted

  • Education only. No predictions. It explains and shows sources. It never recommends a trade or says where a price is going.
  • No made-up numbers. Missing data stays missing, with the reason. Every figure names its source and time.
  • Never your accounts. It never reads balances, account numbers, positions or form fields.
  • Read-only and private. The connector only receives what your assistant asks it, changes nothing and stores none of it.

Or use it in your browser

Prefer not to use an assistant? The web app and the Chrome extension explain whatever you type or highlight, with Gemini Nano on your device first and Gemini in the cloud only when needed. Every answer says which one ran.

The extension reads only the text you highlight, the page title and the site name, and only when you ask.

Sign in

The Chrome extension is not in the Chrome Web Store yet. Until it is listed, the web app has the same Explain, Learn and Assets.

Add the extension from the Chrome Web Store, then pin it and press Alt+Shift+X on any highlight.
